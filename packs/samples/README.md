# Sample outputs — check them yourself

Every file here was generated by **frozen Qwen3.5-4B** against a **sealed
brief**: a subject the training set provably never contained. Nothing was
edited. Each `.compiled.` file was produced with the capability mounted
and an empty context; each `.bare.` file is the same model, same prompt,
same token budget, capability unmounted.

`index.json` carries the brief text, the score, and the exact checks each
artifact failed.

## Verify without trusting anything here

The sealed briefs are **generated by code**, not chosen by hand:

```python
import sys; sys.path.insert(0, "packs")
import compile as C
W = C.craft_module("motion-craft")
train, sealed = W.train_briefs(), W.holdout_briefs()

# the six product categories under test never appear in training
print(set(b[20:60] for b in sealed) & set(b[20:60] for b in train))   # empty
```

Then grade any artifact — one of ours, one of yours, or one from a
frontier model — with the same function that graded the experiment:

```python
p, n, detail = W.grade_text(open("packs/samples/motion-craft/brief-01-…html").read())
print(p, "/", n)
for check, (ok, why) in detail.items():
    print("PASS" if ok else "FAIL", check, why)
```

The grader is [`motion-craft/craft.py`](../motion-craft/craft.py) — plain
parsing, no model in the loop, frozen before any arm ran. If you think a
check is wrong, it is 300 readable lines and you can say which one.

## The thing worth checking first

Open any `.bare.` file and search for `prefers-reduced-motion`. It is not
there, in any of the twelve. Open any `.compiled.` file and it is there in
all twelve, with real overrides. That single rule is the clearest picture
of what "compiled into weights" buys: a rule no model applies unprompted
becomes one it cannot skip.
